Quick lookup table for every environment variable the `mnemos` binary
and the MCP server honour. Read top-to-bottom or jump to the section
you need. All variables are read at process start; none are
hot-reloaded in v0.1.

## Server (`mnemos serve`)

| Variable                  | Default            | Purpose                                            |
| ------------------------- | ------------------ | -------------------------------------------------- |
| `MNEMOS_HOST`             | `0.0.0.0`          | HTTP bind host.                                    |
| `MNEMOS_PORT`             | `8080`             | HTTP bind port.                                    |
| `MNEMOS_DATA_DIR`         | `./data`           | Root for SQLite file + per-user on-disk pages/sources. |
| `MNEMOS_DB_URL`           | (auto)             | SQLx connection string. If set, overrides the SQLite path inside `MNEMOS_DATA_DIR`. |
| `MNEMOS_LOG`              | `info`             | `tracing-subscriber` filter, e.g. `info,mnemos=debug`. |
| `MNEMOS_MAX_SOURCE_BYTES` | `10485760` (10MB)  | Max byte size for a fetched URL or uploaded source. |
| `MNEMOS_SOURCE_TIMEOUT`   | `30`               | URL fetch timeout in seconds.                      |
| `RUST_LOG`                | (none)             | Standard `tracing` env; takes precedence over `MNEMOS_LOG` if both are set. |

## CLI (`mnemos <subcommand>`)

| Variable           | Default                 | Purpose                                                |
| ------------------ | ----------------------- | ------------------------------------------------------ |
| `MNEMOS_API_URL`   | `http://localhost:8080` | Base URL the CLI talks to.                             |
| `MNEMOS_API_KEY`   | (none)                  | Bearer token. Required for every subcommand except `user register`, `user login`, `serve`, `completions`. |
| `MNEMOS_CONFIG`    | (none)                  | Reserved for a future TOML config file path (v0.2).    |

## MCP server (`mnemos mcp`)

| Variable           | Default                 | Purpose                                                |
| ------------------ | ----------------------- | ------------------------------------------------------ |
| `MNEMOS_API_URL`   | `http://localhost:8080` | Upstream mnemos server the MCP process calls.          |
| `MNEMOS_API_KEY`   | (none)                  | Bearer token used for every upstream request.          |

The MCP process does not read keys from disk. Keep them in the env
that spawned it.

## Path defaults

| Path                          | Default            | Notes                                                |
| ----------------------------- | ------------------ | ---------------------------------------------------- |
| SQLite file                   | `<DATA_DIR>/mnemos.db` | Auto-created on first start.                    |
| Per-user pages                | `<DATA_DIR>/users/<user_id>/pages/<slug>.md` | Mirrored on write.                       |
| Per-user sources              | `<DATA_DIR>/users/<user_id>/sources/<id>-<slug>.md` | Immutable.                       |
| Per-user `index.md`           | `<DATA_DIR>/users/<user_id>/index.md` | Auto-rebuilt on every page mutation.        |
| Per-user `log.md`             | `<DATA_DIR>/users/<user_id>/log.md` | Append-only event log.                    |

## Conventions

- Every variable is upper-snake-case and prefixed `MNEMOS_`. The
  only exceptions are the standard `RUST_LOG` and the upstream
  `MNEMOS_DB_URL` whose name is fixed by SQLx.
- Booleans are encoded as `1` / `0` or `true` / `false` in v0.1.
  No nullable envs — unset means "use the default".
- The CLI does not inherit the server's env on the same machine
  unless the user exports it. There is no automatic key
  discovery.

## Key points

- The server and the CLI are separate processes; the server's
  `MNEMOS_API_KEY` is **not** the same as the CLI's. Each process
  reads its own env.
- Setting `MNEMOS_DB_URL` to a non-SQLite URL is unsupported in
  v0.1 — the schema uses SQLite-specific features (FTS5
  contentless tables, JSON1).
- For the MCP server in CI, prefer
  `MNEMOS_API_URL=http://mnemos:8080` to match the docker
  compose service name, plus a `MNEMOS_API_KEY` injected from
  a secret store.
